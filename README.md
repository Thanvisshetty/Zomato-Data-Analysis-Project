# Zomato-Data-Analysis-Project

📌 Project Overview

This project focuses on analyzing Zomato restaurant data to extract meaningful insights related to restaurant ratings, pricing, online delivery, location-based trends, and customer preferences.
The analysis helps understand factors influencing restaurant success and customer satisfaction.

🎯 Objectives

1.Analyze restaurant ratings and pricing trends

2.Study the impact of online delivery and table booking

3.Identify popular restaurant types and cuisines

4.Explore location-wise restaurant distribution

5.Perform data cleaning and exploratory data analysis (EDA)

📊 Dataset Information

Dataset Name: Zomato Restaurant Data

Source: Kaggle / Public Dataset

Format: CSV

Records: Restaurants across different cities

Key Features:

Restaurant Name

Location

Cuisines

Average Cost for Two

Ratings

Online Delivery

Table Booking

🛠️ Tools & Technologies Used

Python

Jupyter Notebook

Pandas – Data manipulation

NumPy – Numerical operations

Matplotlib & Seaborn – Data visualization

🔍 Project Workflow

1.Data Loading

2.Data Cleaning (handling missing values, duplicates)

3.Exploratory Data Analysis (EDA)

4.Visualization of key trends

5.Insights & conclusions

📈 Key Insights

1.Restaurants offering online delivery generally receive higher ratings

2.Certain locations have a higher concentration of top-rated restaurants

3.Average cost influences customer ratings up to a limit

4.Popular cuisines vary significantly by location
